# All Steam Technologies - Netlify demo (to send to the client)

Same design as production, plus a "Demo preview by WebCraft PK" badge and `noindex` so search engines ignore it.

## Deploy
1. Go to https://app.netlify.com/drop
2. Drag this whole folder in.
3. Copy the `*.netlify.app` link and send it. Optionally rename it under Site configuration > Change site name.

The quote form works on Netlify (submissions show in the Netlify dashboard). Placeholder reviews and sample before/after cards are labeled, so the client knows what needs real content.
